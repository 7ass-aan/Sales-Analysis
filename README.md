# 💼 Employee Salary Analysis

An Excel-based data analysis project exploring employee salaries, departments, job roles, experience, and other workforce characteristics.

## 📊 Project Overview

This project analyzes employee salary data using Microsoft Excel to explore salary patterns and understand how compensation varies across different employee attributes.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning & Transformation
* PivotTables
* Data Analysis
* Data Visualization
* Interactive Dashboard
* Business Insights

## 🔍 Analysis

The project explores employee compensation from several perspectives, including:

* Salary distribution across departments
* Salary differences by job title
* Salary analysis by location
* Relationship between experience and salary
* Salary patterns across education levels and other employee characteristics

## 📈 Dashboard

An Excel dashboard presents key salary metrics and analysis in a clear, organized format to support data exploration and comparison.

## 🎯 Project Goals

* Analyze employee salary data
* Explore compensation patterns across different workforce categories
* Practice data analysis using Microsoft Excel
* Present findings through PivotTables and dashboard visualizations
* Develop practical analytical and business understanding

## 📁 Project Files

* `employee_salaries.xlsx` — Raw employee salary dataset.
* `Salary Analysis.xlsx` — Excel workbook containing the analysis and dashboard.
